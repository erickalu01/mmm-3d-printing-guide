2A

Changing filament color

When filament is already on the spool

Filament = the colored plastic wireSpool = the gray wheel it's wound on
Watch the instruction videoOpens on YouTube
  1. Remove the old spool
    Push the gray tab in and roll the filament backwards out of the machine.
  2. Insert the new spool
    Before loading it into the machine, make sure the spool is secured correctly and tightly.
    ⚠️ The two halves of the spool should be firmly connected, not loose or crooked. If the filaments are not correctly spooled or loaded, this will eventually cause an error and the filament will become unspooled = unusable!!
  3. Feed it in
    While holding the gray tab in, feed about 1 inch of filament, then let go of the tab.
  4. Let it calibrate
    The machine auto-calibrates the new filament. No action needed.
2B

Loading new filament color into an empty spool

  1. Grab an empty spool and your plastic filament
  2. Open the empty spool
    Untwist the spool to open it into 2 halves.
  3. Line up the notches
    The inside of the filament has a notch in the cardboard. Match that notch to the plastic notch on one of the spool halves. Once the notches are aligned, the filament should be secure in place.
  4. Close the spool
    Place the other half of the spool on top and twist until you hear an audible “CLICK”.
  5. Load it into the machine
    You can now load the spooled filament into the machine for use. Follow the steps in 2A.
3

Printing

  1. Create or find a file to print
    A few ways to get one:
    a
    Search Google. Try something like "3D print files for a picture frame". Sites like Printables have free, open-source files to download.
    b
    Use Bambu's library. Download ready-made print files right from the Bambu Studio desktop app or the Bambu Handy mobile app.
    c
    Ask AI to help. e.g. "Make me a 3D print file of a picture frame for Bambu Studio"
  2. Open your file
    If it's the right file type for 3D printing (.3mf or .stl), it should open in Bambu Studio.
  3. Make sure the printer is set to Bambu Lab H2C
  4. Set up colors in the Prepare tab
    a
    Choose the nozzle size. Standard is 0.4.
    ⚠️ Never go below 0.4 for special filaments like metallics.
    b
    Match the filament type to the spools you're printing with. The type is printed on each spool.
    SparkleMetallic filaments
    SilkHolographic / iridescent
    BasicSolid colors
  5. Switch to the Preview tab
  6. Click Print Plate in the upper-right corner
  7. Choose an available printer
    MMM 3D Printer 1 MMM 3D Printer 3 MMM 3D Printer 4
  8. Choose filament colors
    Match each color in your model to a spool loaded in the printer's AMS.
  9. Hit Send to start printing
    Before you hit send, check the rules below 👇
4

Lounge etiquette

🤝

Share the machines

Be mindful of how often you print and how many printers you use at once, so everyone gets a fair turn.

🛑

Clear the plate first

Never send a print remotely until the previous print has been removed and the plate is placed back in the machine.
